# Aerodinamik Web Sitesi (Başlangıç)

Bu repo şu an iki temel sayfadan oluşur:

1. **Ana Sayfa (`index.html`)**
   - Üst menüde sayfalar arası geçiş butonları
   - "Aerodinamik" başlığı
   - Düz renk geçişli, animasyonlu arka plan

2. **Dergiler Sayfası (`dergiler.html`)**
   - Dergi adı, sayı ve tanıtım metni ile yeni içerik ekleme
   - Eklenen dergileri kartlar halinde listeleme
   - Tek tek silme veya tümünü temizleme
   - Verilerin tarayıcıda saklanması (`localStorage`)

## Çalıştırma
Proje saf HTML/CSS/JS'dir.

```bash
python3 -m http.server 8000
```

Tarayıcıdan: `http://localhost:8000`
